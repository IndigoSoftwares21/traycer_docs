Fifteen endpoints over five resources. Every page in this section has a live playground — paste an API key into the **Authorization** panel and send a real request.

## Base URL

```bash
https://traycercoinsbe-production.up.railway.app/api/v1/http
```

<Note>
  The playground on every page below sends to this base. The `v1` segment comes from the server's `API_VERSION` setting and defaults to `v1`.
</Note>

## Authentication

Every request carries an API key in the `x-api-key` header:

```bash
curl $BASE/wallets -H "x-api-key: trc_live_a1b2c3d4_9f8e7d6c5b4a3f2e1d0c9b8a7f6e5d4c"
```

Keys are scoped `read` or `read_write`. Each endpoint below states which it needs. Full details in [Authentication](/guides/authentication).

## Conventions

<AccordionGroup>
  <Accordion title="One envelope for every response" icon="box">
    ```json
    { "message": "Wallets retrieved successfully", "code": 200, "data": { } }
    ```

    `data` is `null` — not absent — when there is nothing to return. Errors drop `data`; validation failures add `validationErrors`. See [Errors](/guides/errors).
  </Accordion>

  <Accordion title="Missing resources return 400" icon="magnifying-glass">
    Existence is checked during request validation, so an unknown wallet reference or transaction hash surfaces as a field-level `400`, not a `404`.
  </Accordion>

  <Accordion title="Amounts are in whole units" icon="coins">
    `100` means 100 USDT, never 100000000 base units. `coinDecimals` from `GET /networks` is informational only.
  </Accordion>

  <Accordion title="Timestamps are ISO 8601 UTC" icon="clock">
    `2026-08-07T14:22:31.000Z`. Large integers may serialize as strings — parse numerically.
  </Accordion>

  <Accordion title="Rate limited per IP" icon="gauge-high">
    60 requests per minute in production, shared across everything behind the same address. `429` responses do not use the standard envelope. See [Rate limits](/guides/rate-limits).
  </Accordion>
</AccordionGroup>

## OpenAPI specification

The full spec is published at [`/openapi.yaml`](/openapi.yaml). Import it into Postman, Insomnia, or a code generator:

```bash
curl -O https://your-docs-domain.com/openapi.yaml
npx @openapitools/openapi-generator-cli generate -i openapi.yaml -g typescript-fetch -o ./traycer-client
```

It also declares the two outbound webhook events, so generators that support OpenAPI 3.1 `webhooks` will produce types for your event handler as well.
